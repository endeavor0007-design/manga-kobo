# まんが化工房（小説・原作の漫画化／AI作画）

https://cocreturn.com/manga-kobo/

小説・Web小説・原作の文章を漫画にするサービスです。原作を読んでネーム（コマ割り）を作り、生成AIで作画し、日本語の縦書きのセリフ入れとページ組みまで一式で仕上げます。

- 開発中のため、冒頭1ページ（3〜5コマ・白黒）の無料お試しを先着10名で受け付けています
- 有料は受付開始前です（予定：有料サンプル1ページ1,500円・2ページ以上はお見積り）
- 用途：小説の宣伝・試し読み・正式なコミカライズの前の試作
- 作画は生成AIです。生成AIの作品を受け付けない賞には使えません
- 原作はご本人の作品だけをお受けします
